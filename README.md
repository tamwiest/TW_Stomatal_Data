Stomatal Aperture:
  Column Titles:
    Treatment: Treatment code with four parts: Cultivar Code ('Black Seeded Simpson' = BSS; 'Flandria' = FLA; 'Mascara' = MAS; 'Outredgeous' = OUT) . Leaf Side (T=Adaxial/top; B=Abaxial/bottom) . Microgravity Treatment (0= 0 RPM for Normal Gravity; 4= 4 RPM to Simulate Microgravity) +/- Salmonella
    Area: Area of the stomatal pore
    Minor (um): The minor axis of the stomatal pore
    RPM: Microgravity treatment, where 0 = 0 RPM for Normal Gravity and 4 = 4 RPM to Simulate Microgravity
    Salmonella: 0 = Sterile mock inoculation with phosphate buffered saline (PBS) on the abaxial surface or 1 = OD600 of 0.8 GFP Tagged Salmonella enterica suspended in PBS inoculation on the abaxial surface
    Leaf: Leaf replicate
    Cultivar: Cultivar Code ('Black Seeded Simpson' = BSS; 'Flandria' = FLA; 'Mascara' = MAS; 'Outredgeous' = OUT)
    Leaf Side: Top = adaxial or Bottom = abaxial
    ABA: Presence or absence of 10 uM abscisic acid
